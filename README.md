# Sawriya Travels Website

This package contains the complete static source code for the Sawriya Travels website.

## Files

- `index.html` - website content and structure
- `style.css` - responsive design and styling
- `app.js` - enquiry form, filters, and interactions
- `jaipur.jpg` - Jaipur destination image

## Run locally

Open `index.html` in a browser, or upload all files together to any static hosting provider.

## Important

The WhatsApp and call buttons are connected to the business number configured in the website code. The destination image credit is included in the footer.
